# Nicolás Rodríguez

Game Producer | Game Designer | Gameplay Programmer

I make games and help teams get them built. My work connects game direction and production with mechanics design, gameplay programming, and VFX. I enjoy working through both the overall direction of a project and the details that make it playable.

Fuenteki Studio is part of that work. I also create mods and prototypes, and worked as a QA Tester intern at Whiteboard Games on Tempus Vitae.

## Selected Work

- [Jigsaw Jab](https://store.steampowered.com/app/4107020/Jigsaw_Jab/) — Direction, production, and design on an action game where defeated enemies become puzzle pieces.
- [Snowballing](https://fuenteki.itch.io/snowballing) — Game design and development, from core gameplay to progression and interfaces.
- [Tempus Vitae](https://play.expoeva.com/showroom-2026/tempus-vitae/) — QA testing at Whiteboard Games.
